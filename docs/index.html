lexxy-math

KaTeX-based math for Lexxy

npm GitHub

Editor

  • Type $E=mc^2$ for inline math.
  • Type $$ on an empty line and press Enter for block math.
  • Click any math to edit it with a live preview; press Escape or ⌘/Ctrl+Enter to confirm.
  • Bold, italic, underline, strikethrough, colors and links apply to selected math.
